অ্যাডমিন লগইন

অ্যাডমিন লগইন নম্বর: 01768487228

প্রথমে Firebase-এ আপনার অ্যাডমিন অ্যাকাউন্টের পাসওয়ার্ড সেট/রিসেট করুন। শুধু ZIP ফাইল দিয়ে Firebase-এর পাসওয়ার্ড বদলানো যায় না।

কাস্টমার সাইট দেখুন

পণ্য যোগ / সম্পাদনা

ফ্রি সংস্করণে ছবিটি আগে অন্য ইমেজ হোস্টিংয়ে আপলোড করে সরাসরি HTTPS ছবির লিংক দিন। Firebase Storage ব্যবহার হয় না।

ছবি Firebase Storage-এ আপলোড হবে। একাধিক ছবি বেছে নিতে Ctrl/Shift বা মোবাইলে একাধিক নির্বাচন ব্যবহার করুন।
